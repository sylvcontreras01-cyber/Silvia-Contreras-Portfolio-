# Instrucciones para agregar tus imágenes

Coloca aquí tus archivos de imagen con estos nombres exactos:

## Fotos personales
- `TU_FOTO_AQUI.jpg` → Tu retrato editorial principal — se usa en el HERO y en "Sobre Mí"
- `gallery-1.jpg` al `gallery-6.jpg` → Tus fotos de branding personal

## Imágenes de proyectos
- `project-chocolate.jpg`    → Portada del proyecto Historia del Chocolate
- `project-lideresas.jpg`    → Portada del proyecto Lideresas Indígenas
- `project-red.jpg`          → Portada del proyecto Red de Conexiones
- `project-regeneracion.jpg` → Portada del proyecto Regeneración Urbana
- `project-noticias.jpg`     → Portada del proyecto #NoticiaESL

## Notas
- Formato recomendado: JPG o WebP
- Resolución recomendada: mínimo 800×600px para proyectos, 600×800px para fotos verticales
- Si una imagen no carga, el sitio muestra un placeholder de color automáticamente
